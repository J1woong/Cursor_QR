# QR 코드 생성 · 읽기 웹앱

브라우저에서 바로 실행 가능한 단일 페이지 QR 도구입니다.

- 텍스트/URL을 QR 코드로 생성
- 생성한 QR을 PNG로 저장
- QR 이미지 파일 업로드 후 내용 디코딩
- 디코딩 결과가 URL이면 바로 열기
- 다크/라이트 모드 전환
- Lucide 아이콘 사용

---

## 1) 프로젝트 개요

이 앱은 별도 빌드 도구 없이 `index.html` 하나로 동작하도록 구성되어 있습니다.

주요 사용 시나리오:

1. 링크를 빠르게 QR로 만들어 공유
2. 받은 QR 이미지에서 URL/텍스트 추출
3. 모바일 화면/인쇄물 QR 테스트

---

## 2) 파일 구조

현재 폴더 기준:

- `index.html` : 앱 전체(UI/CSS/JS)
- `README.md` : 사용/개발 문서

## 3) 실행 방법

### 가장 간단한 방법

1. `index.html`을 더블클릭해 브라우저로 엽니다.
2. 화면에서 바로 사용합니다.

### 로컬 서버로 실행(권장)

브라우저 보안 정책 이슈를 줄이려면 로컬 서버 실행을 권장합니다.

예시 (PowerShell):

```powershell
cd "c:\Users\USER\OneDrive\바탕 화면\Vibe\QR"
python -m http.server 5500
```

브라우저에서 `http://localhost:5500` 접속

## 4) 주요 기능

### A. QR 생성

- 입력: 텍스트/URL
- 옵션:
  - 크기(px): 64~1024
  - 오류 복원: L / M / Q / H
- 출력: 화면 미리보기 + PNG 저장

### B. QR 이미지 읽기

- 입력: PNG/JPG 등 이미지 파일
- 동작:
  1. 이미지 로드
  2. 캔버스로 샘플링
  3. `jsQR`로 디코딩
- 결과:
  - 원문 텍스트 표시
  - URL이면 `링크 열기` 버튼 활성화

### C. 테마 전환

- 다크/라이트 모드 토글
- 선택값은 `localStorage`(`qr-theme`)에 저장되어 다음 실행 시 유지

## 5) 사용 라이브러리

현재 `index.html`에서 CDN으로 로드:

- `qrcodejs` (QR 생성)
- `jsQR` (QR 디코딩)
- `lucide` (아이콘)

참고:

- 인터넷 연결이 없으면 CDN 리소스 로드 실패로 기능이 제한될 수 있습니다.
- 완전 오프라인용이 필요하면 라이브러리를 인라인/로컬 파일로 변경하세요.

---

## 6) 커스터마이징 가이드

### 테마 색상 변경

`index.html`의 `:root`, `[data-theme="light"]` CSS 변수를 수정:

- `--bg`, `--card`, `--text`, `--muted`
- `--accent`, `--border`, `--field`

### 기본 QR 크기 변경

`id="size"` 기본값(`value`) 또는 스크립트 기본값 수정.

### URL 판정 규칙 변경

JS의 URL 판정 함수(`resolveOpenHref`)에서:

- 허용 스킴
- `www.` 자동 보정

정책을 필요에 맞게 조정할 수 있습니다.

### 아이콘 변경

버튼/링크 요소의 `data-lucide` 값을 원하는 아이콘 이름으로 바꾸면 됩니다.

## 7) 문제 해결(Troubleshooting)

### 1) 아이콘이 안 보임

- 네트워크에서 `unpkg`가 차단되었을 수 있습니다.
- 개발자 도구 콘솔에서 CDN 로드 실패 여부 확인
- 필요 시 로컬 번들/인라인 방식으로 전환

### 2) QR 생성이 안 됨

- 입력값이 비어 있는지 확인
- `qrcodejs` 로드 실패 여부 확인

### 3) 업로드한 QR을 못 읽음

- 이미지 해상도가 너무 낮거나 흐릿한 경우
- QR가 너무 작게 찍힌 경우
- 기울어진 사진/강한 반사/노이즈가 큰 경우

개선 방법:

- 원본 해상도 높은 이미지 사용
- 정면에 가깝게 촬영
- 대비가 높은 이미지 사용

### 4) 링크 열기가 안 뜸

- 디코딩 결과가 URL 형식이 아닐 수 있습니다.
- `http://`, `https://`, `www.` 규칙에 맞는지 확인
